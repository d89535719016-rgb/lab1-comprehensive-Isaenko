
## Аудит программного обеспечения (Практическая работа 8, Часть 2)

### 1. Выбор и обоснование категорий базового ПО
* **Офисный пакет (LibreOffice/МойОфис):** Необходим для работы с текстовыми документами (.docx) и таблицами (.xlsx).
* **Архиватор (7-Zip/WinRAR):** Обязателен для распаковки рабочих материалов и сжатия вложений перед отправкой по почте.
* **Программа для PDF (Foxit/SumatraPDF):** Требуется для открытия инструкций, регламентов и договоров без возможности случайного редактирования.
* **Браузер:** Рабочее место должно иметь современный веб-браузер для доступа к корпоративным веб-сервисам и CRM.
* **Антивирус:** Обеспечивает базовую безопасность конфиденциальных данных компании.

### 2. Признаки излишнего ПО
* **Игры:** Снижают продуктивность сотрудников на рабочем месте, занимают дисковое пространство.
* **Торренты:** Создают критическую нагрузку на сеть, забивают канал и могут служить источником вирусов.
* **Мессенджеры:** Используются для личного общения, если не входят в официальный корпоративный стандарт связи.
* **Мультимедиа:** Сторонние плееры и инструменты кастомизации (например, Wallpaper Engine) не требуются для выполнения офисных задач.

### 3. Ограничения решения
Скрипт выполняет поверхностный анализ по сигнатурам из реестра Windows. Он не может обнаружить портативные версии программ (Portable), которые запускаются из папок или с флешек без интеграции в систему.
